## 五分钟速览

### 这本书在说什么

历史学为什么永远有争论？同一个对象，材料越来越多，共识却没有随之增加。本书不谈“历史是什么”，而是诊断“诠释在做什么”。

### 一句话主张

**历史诠释，就是给一组互相竞争的命题分配置信度。**“他确实说过这句话”置信度高，“他因此被排挤”置信度中，“这标志一个时代的转向”置信度低。争论的分歧，大多是**分配位置**的分歧，而不是事实的分歧。

> 诊断不等于判决，但诊断包含判断——本书不假装中立，而是把判断显式化，使它可被反驳。

### 本书自己的核心 vs 借来的联系

本书有自己独立的核心（**置信度分配**），不依赖前四本书的结论。四个概念只是**借用**来建立联系的词汇：

| 借来的约束 | 相连的著作 | 作用 |
|---|---|---|
| 容量 | 《遗忘的边界》 | 置信度不可能均匀分配，必须先压缩 |
| 权衡 | 《选择的代价》 | 完备、可组合、传递三选二 |
| 时间错配 τ | 《错位的时间》 | 诠释时间 ÷ 历史时间，决定分辨率 |
| 区分 | 《区分的语法》 | 诠释即区分，边界必须被标记 |

**是“联系”，不是“依赖”**：若某个借用不成立，本书的核心不受影响。

## 主要论断（带证据强度）

| 论断 | 强度 |
|---|---|
| 诠释可读成置信度的分配，且可分为观察/推理/诠释/因果四层 | 论证，B／乙 |
| 三种学术风格（清晰/平衡/细节）各占 C-A-T 一个顶点，各让出一个 | 论证，B／乙 |
| 框架在放大时会退化：快速诊断丢掉时间维度 τ | 论证，B／乙 |
| 古代史结论的“确定性虚高”来自压缩而非史料质量 | 假说，B／乙（O3） |
| 历史学范式转移由约束改变驱动，而非真理逼近 | 假说，B／乙（O18） |
| 跨学科冲突主要是位置冲突，而非证据冲突 | 假说，B／乙（O19） |

证据等级：**A** 官方可复现 / **B** 稳定公开估计 / **C** 稀疏·构造·思辨；概念等级：甲/乙/丙。

## 全书结构

- **第一部分　最小内核（第 1—5 章）**：问题、核心、约束、边界。
- **第二部分　由深而广：五个应用（第 6—16 章）**：人物还原 → 跨文明制度对比 → 既有争论诊断 → 理论统摄 → 范式流变。
- **第三部分　元反思（第 17—18 章）**：跨学科的权衡冲突、诠释的责任。
- **第四部分　边界与纲领（第 19—20 章）**：用诊断别人的标准诊断自己，标出证据边界。

## 边界（本书不做什么）

- **不**判定任何史学争论中哪一派正确；
- **不**给出任何断代史结论；
- **不**预测历史研究的下一波范式（只给方向）；
- **不**在跨文明比较中保持中立（框架带有其来源传统的关注点，见第 5.5 节）；
- **不**宣称这套诊断可以被形式化为一组可计算的不等式——该强主张已被撤回并记录在附录 J。
