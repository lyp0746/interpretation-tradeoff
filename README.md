## 五分钟速览

### 这本书在说什么

历史学为什么永远有争论？同一个对象，材料越来越多，共识却没有随之增加。本书不谈“历史是什么”，而是诊断“诠释在做什么”：任何历史诠释都不是对过去的复制，而是在四重约束下的一次选择。

### 一句话主张

**历史学中的持久争论，大多不是谁对谁错，而是不同诠释者在同一张价目表上选择了不同的位置；把选择与代价标注出来，比判定胜负更有用。**

### 四把诊断工具（来自前四本书）

| 工具 | 来源 | 诊断什么 |
|---|---|---|
| 容量级联 | 《遗忘的边界》 | 诠释者必须先压缩；四层（观察/推理/诠释/因果）逐层变软 |
| C-A-T 三角 | 《选择的代价》 | 完备（C）、可组合（A）、传递（T）至多满二 |
| 时间错配 τ | 《错位的时间》 | 诠释时间与历史时间的比率，决定分辨率 |
| 区分与边界 | 《区分的语法》 | 诠释即区分；边界必须被标记 |

### 核心结构

历史学的三种风格各占三角的一个顶点：

- **清晰论** 最大化 C（因果清晰），让出 T（细节传递）；
- **平衡论** 最大化 A（维度丰富），让出 C；
- **细节论** 最大化 T（细节传递），让出 C。

争论之所以持久，是因为**三方用的不是同一把尺子**。

## 主要论断（带证据强度）

| 论断 | 强度 |
|---|---|
| 三场持久争论（帝国衰落、科学革命、法国大革命）呈现同一种“清晰—平衡—细节”结构 | 论证，B／乙 |
| 三种风格可映射到 C-A-T 三个顶点，各让出一个 | 论证，B／乙 |
| 古代史结论的“确定性虚高”来自压缩而非史料质量 | 假说，B／乙（可证伪，O3） |
| 历史学范式转移由约束条件改变驱动，而非真理逼近 | 假说，B／乙（O18） |
| 跨学科冲突主要是位置冲突，而非证据冲突 | 假说，B／乙（O19） |

证据等级：**A** 官方可复现 / **B** 稳定公开估计 / **C** 稀疏·构造·思辨；概念等级：甲/乙/丙。

## 全书结构

- **第一部分　诊断框架（第 1—5 章）**：把四把工具改造成史学诊断语言，并给出证据分级与适用边界。
- **第二部分　深度诊断（第 6—11 章）**：六场持续百年以上的史学争论——帝国衰落、中国统一与欧洲分裂、大分流、科学革命、法国大革命、气候与社会崩溃。
- **第三部分　快速诊断（第 12 章）**：三十场争论的权衡坐标，并追问“这些规律是不是框架的投射”。
- **第四部分　元反思（第 13—15 章）**：范式转移的约束解释、跨学科的权衡冲突、诠释的责任。
- **第五部分　边界与纲领（第 16—17 章）**：把诊断系统放上手术台，标出证据边界与开放问题。

## 边界（本书不做什么）

- **不**判定任何史学争论中哪一派正确；
- **不**给出任何断代史结论；
- **不**预测历史研究的下一波范式（只给方向）；
- **不**在跨文明比较中保持中立（框架带有其来源传统的关注点，见第 5.5 节）；
- **不**宣称这套诊断可以被形式化为一组可计算的不等式——该强主张已被撤回并记录在附录 J。
