第 3 章　置信度的四层：从观察到因果

如果一个诠释者不可能完整处理过去，那么他把高置信度堆在了哪一层？本章把置信度的分配拆成可观察的四层，并给出一个判据：一个诠释的可靠程度，不会高于它最弱的那一层的证据强度。

本章主张 历史诠释可以分解为四个逐级上升的层次：观察（L1）→ 推理（L2）→ 诠释（L3）→ 因果（L4）。随层次上升，可核对手段递减、允许分配的置信度应递减；而学术写作最常见的失配，是在 L4 上用了 L1 的置信度。把每一层分开标注，是诊断的起点。［论证，B／乙］

3.1　导论：一个诠释者在做几件事

“他诠释了这段历史”是一句含糊的话。它至少包括四件不同的事：他读了什么、他推出了什么、他赋予了它什么意义、他声称它导致了什么。这四件事的证据要求完全不同，却常常被写在同一句话里。

举一个虚构但典型的句子：“边防军费上升迫使中央削减对地方的拨款，地方精英因此转向自立，最终使中央失去了对边疆的控制。”这句话里塞进了四种操作：一个观察（军费上升）、一个推理（中央削减拨款）、一个诠释（精英转向自立）、一个因果声称（失去控制）。四种操作的可靠性依次下降，但句子把它们写成了同一种肯定语气。

本章的目的，就是把这种“语气与证据的错配”显形。方法是把诠释拆成四层，逐层追问：这一层的证据是什么？它容许我们说多强的话？

3.2　L1 观察层：文献说了什么

L1 是“文献说了什么”。它是四层中最可核对的一层：一份墓志的年代、一段奏疏的措辞、一条账簿的数字，原则上可以被其他研究者复核。历史学的专业训练主要就集中在这一层。

但 L1 也不是“给定”的。它已经包含一次压缩：从所有可能保存下来的记载中，选出“相关”的那一部分。这个选择受制于两件事——材料保存了什么（幸存偏差）和诠释者关心什么（问题框架）。一份没有被书写、或没有被保存的记录，不会因为研究者的勤奋而出现。

警告 3.1　L1 的两种偏差 幸存偏差：能留下来的材料，本身经过了当时权力与偶然的筛选。碑刻多于书信，官修多于私记。
选择偏差：研究者的问题决定了什么被当作“相关材料”。换一个问题，同一批材料会呈现出不同的面貌。［警告，甲］

因此，说“L1 是最可靠的层”，意思是它最容易被核对，不是它没有失真。它的失真可以被公开讨论，这正是它可靠的原因。

3.3　L2 推理层：它意味着什么

L2 是“这些材料意味着什么”。从“某人写了这封信”到“某人持有这种立场”，中间隔着一次推理。推理可以是谨慎的，也可以是跳跃的，但无论如何，它都会丢掉一些东西。

L2 的典型困难是意图的不可观测。我们能看到一个人写了什么，看不到他为什么写。一个学者可以从文本、情境、生平推出一系列可能，但无法把“可能”变成“确知”。当写作把“文献显示他反对 X”与“他因为 Y 而反对 X”并列时，它其实把 L1 与 L2 混在了一起。

L2 的可靠性取决于推理链的长度与每一步的稳健程度。一条由五个小步组成的推理，比一条由一个大跳组成的推理更容易被检查，但也更容易被逐点反驳——这是压缩与可核对性的又一次交换。

3.4　L3 诠释层：意图与时代逻辑

L3 是“这属于什么意义结构”。在这一层，学者不再只问“他做了什么”，而问“他在一个时代逻辑里处在什么位置”。例如，把某人的言行解释为“对儒学失效的诊断”，或者“对皇权合法性的争夺”，都是 L3 的操作。

L3 是历史诠释最有价值、也最危险的一层。它的价值在于：正是它把零散的观察组织成可理解的整体。它的危险在于：时代逻辑是诠释者构造的，不是史料给出的。“儒学失效”“合法性危机”“士族转型”这些概念，在史料里往往并不以一个概念的形式出现，而是研究者用来统摄材料的一个框架。

定义 3.1　L3 的投射风险 当一个诠释声称“当时的人知道/感受到 X”时，如果史料只支持“他们做了与 X 相关的行为”，那么这个声称就包含一次投射：把自己的解释框架，读成了当事人的意识内容。［定义，乙］

投射不是错误，它是理解的必要条件——没有框架，材料无法被理解。但投射的深度是分等级的。“他反对某政策”可能只需要很浅的投射；“他意识到整个论证体系正在失效”则需要很深的投射。诊断要做的是把投射的深度标出来，而不是禁止投射。

3.5　L4 因果层：它导致了什么

L4 是“它导致了什么”。这是四层中自由度最大、也最常被写成定论的一层。原因很简单：历史因果无法通过实验检验。我们无法把同一个过去重放两遍，一遍有 X，一遍没有 X。

L4 的困难不只是“缺少反事实”。即使有反事实推理（“如果 X 没有发生”），它也建立在假设之上，而假设本身可以争一百年。因此，L4 的结论几乎总是事后构造的：从一个已知的结果出发，回头找一条让它看起来必然的路径。

这不意味着 L4 毫无价值。相反，没有 L4，历史学就只是编年与考据，无法回答“为什么”。问题只在于写作的诚实度：一个 L4 断言应当被标明为“一种因果解释”，而不是被写成与 L1 同等地位的“事实”。

事后构造的两种形态 收敛式：把多条独立线索收束到一个原因上（“这些现象都指向制度僵化”）。
发散式：从一个结果展开成多重条件（“这是 A、B、C 共同作用的结果”）。
前者是清晰论，后者是平衡论。二者都从事后出发，只是收敛与发散的方向相反。［论证，乙］

3.6　置信度的衰减与注意力占用

把四层排成一条链（图 3.1），可以得到一个诊断表。它的核心读数是“每一层容许的置信度”。

表 3.1　四层的可核对性与容许置信度
层典型内容可核对性解释自由度容许的置信度
L1 观察文献、年代、措辞、数字高低强（可称“事实”）
L2 推理文本的含义、作者的立场中中中（宜称“可推断”）
L3 诠释意义结构、时代逻辑、意图低较高弱（宜称“一种解释”）
L4 因果导致、因此、必然最低最高最弱（宜称“一种因果假说”）
可核对性与自由度为定性排序（甲），非定量测量；“容许的置信度”是规范建议，其依据是第 5.2 节的证据分级纪律。
图 3.1　置信度的四层——随层数上升，可核对性递减、解释自由度递增；最常见的问题是“置信度高于证据”。

“置信度衰减”这个词需要小心。它不是道德评判，而是一个结构事实：随着层数上升，可核对的证据相对于解释自由度在减少。一个学者可以在 L4 上做出正确判断，但他无法像在 L1 上那样证明它。在 L4 上分配 L1 的置信度，就是把结构上的不确定伪装成语气的确定。

容量占用是另一个读数。一个诠释者的有限注意力总要分配到某一层：偏重 L1 的人做考据，偏重 L2–L3 的人做思想史，偏重 L4 的人做宏大叙事。占用的分布，直接反映为学术风格。这不是缺陷，而是分工——只是分工需要被说明。

3.6.1　诠释作为一次带先验的更新

四层分解还可以换一种说法：一个诠释就是一次置信度更新。诠释者带着先验——他所在学科的问题框架、他读过的文献、他对某类史料可靠性的判断——面对新证据，得到一个后验分配。用这套语言，第 1 章的三种风格可以被读成三种不同的先验强度：先验越强，新证据对结论的修正越小，结论越干净（C 高），也越难被细节撼动（T 低）。第 6 章会把这条线索展开为应用一：用贝叶斯与置信度还原具体的人物与事件。

这个类比的价值不是把史学变成贝叶斯计算——它做不到，因为史学中的先验无法被数值化，也无法在无争议的模型下比较。它的价值在于提醒一件事：当一个诠释看起来“证据充分”时，要分清哪一部分来自证据、哪一部分来自先验。前者可以被新史料修正；后者不能。

警告 3.2　不要把先验当噪声 先验不是需要被消除的偏见，它是理解得以发生的条件——没有先验，材料不产生意义。诊断要做的不是消灭先验，而是把它的强度标出来：一个强先验的诠释，其结论对新证据的敏感度低。（见第 5.2 节的证据分级与 O1。）［警告，乙］

3.7　一个完整例子：从一句话到一条因果链

下面用一个示意性的例子把四层走完。它不针对任何具体学者，只用来展示诊断的形态。

假设一位学者写了一句话：“地方官员无法在现行官僚体系内获得晋升，于是转向经营本地网络。”

表 3.2　对一句话的四层分解（示意）
层这句话里对应的成分需要的证据本书评级
L1“地方官员……”“本地网络……”哪些人、哪些年代、哪些记载A—B
L2“无法在官僚体系内获得晋升”他们曾尝试晋升，且失败的证据B—C
L3“转向经营本地网络”这一转向是有意识的选择，而非无意的结果C
L4“于是”因果替代关系：先有挫败，后有转向，且前者导致后者C
本表为方法示范，其中的“本书评级”是对该句式所需证据的评级，而非对任何真实研究的评价。

诊断的结论不会说“这位学者错了”。它会说：这句话的 L1 部分很稳，L4 部分是一个因果假说；如果作者在写作时把 L4 标成了“一种可能的解释”，这句话的可靠性会显著提高。诊断给的是形式上的定位，不是内容上的判决。

置信度层诊断的三个读数 面对任何一个诠释，置信度层给出三个读数：（1）哪一层证据最弱；（2）作者在哪一层用了最高的置信度；（3）两层是否匹配。最常出现的问题，是（2）高于（1）。［论证，B／乙］
