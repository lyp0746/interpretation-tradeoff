第 17 章　历史学范式转移的约束解释

应用四把现有的历史理论摆在了同一张坐标图上，那是一张共时的图。本章把它竖起来看——如果每个理论都占一个位置，那么位置的迁移（范式转移）又是被什么推动的？结论是有力的，也是有条件的：范式的更替主要由约束改变驱动，而不是因为新范式“更接近真理”。

本章主张 历史学从宏大叙事到社会史、再到微观史与全球史的迁移，可以被读成轨迹在三角上的移动。每一次移动都伴随两种约束的变化：可获得的资料量与学术共同体的认知环境。范式不是被证伪的，而是在新约束下“旧位置不再划算”而被替换的。这不意味着真理无用，而意味着真理不是唯一的驱动力。［假说，B／乙］

17.1　导论：范式为什么换

史学史通常把范式转移讲成“史观的进步”：从民族国家的宏大叙事，到社会史的多元分析，再到微观史的细节还原。这个叙事假定后来的范式更成熟、更接近真实。

本章提出一个不同的读法：把它看作选择位置随约束变化的迁移。判据很简单——如果转移由“更真”驱动，那么旧范式应当被证据驳倒；如果转移由约束驱动，那么旧范式可以在新的证据环境下仍然“自洽”，只是不再划算。

这个读法可以用一句可检验的话概括：范式的位置，应当与其时代可获得的资料量和认知环境相关。下面按三个时代检验。

17.2　宏大叙事时代：资料稀缺下的高 C

十九世纪到二十世纪中期，历史学的主流带有强烈的宏大叙事特征：民族史、文明史、通史。它的典型形态是给出清晰的因果与阶段，把漫长历史组织成可理解的线索。

当时约束条件的关键特征是资料相对稀缺、获取成本高、且集中在政治与精英记录。在资料稀少的情况下，要写出连贯的历史，诠释者不得不依赖强假设来填补空白——而强假设会产生清晰的因果链（高 C）。因此，高 C 不只是一种风格偏好，它是资料约束下的理性选择。

它的代价是 T：细节难以传递，后代研究者若要修正，往往只能整体重写。这也解释了为什么宏大叙事很容易被“推翻”——不是因为它错，而是因为它缺乏让后来者在局部上修补的接口。

17.3　社会史时代：资料增加后的高 A

二十世纪中期以后，社会史（含年鉴学派）崛起。它的特征是纳入大量社会维度：人口、价格、土地、阶级、家庭、地方社会。研究单位从“国家与伟人”扩展到“社会与结构”。

约束条件发生了两个变化：资料大量增加（档案开放、统计材料、口述传统），以及社会科学方法进入史学（经济学、社会学、人类学提供分析工具）。资料增加使高 C 的强假设变得不必要，也使其显得可疑；分析工具的丰富使多维并列成为可能。于是轨迹从高 C 迁移到高 A。

社会史的代价是 C：当所有维度都重要，历史解释失去了“决定因素”。这带来了一个新形式的争论：多元分析究竟是成熟，还是逃避了因果责任？

17.4　微观史时代：数据过载下的高 T

二十世纪后期到二十一世纪初，微观史兴起。它把镜头对准一个村庄、一个家庭、一次审判、一个人。它的证据密度极高，细节可核对，结论可累积。

约束条件再次变化：资料从“增加”变成“过载”，加上档案数字化与检索工具。当一个人面对的材料远超任何一个大脑所能整合时，追求高 C 的综合变得不现实；相反，把一个小单元做透，是唯一能在资源约束下保证质量的选择。于是轨迹迁移到高 T。

微观史的代价仍是 C：它难以回答“整个时代发生了什么”。这不是研究者短视，而是约束下的必然取舍——把大问题交给微观方法，反而会产生一堆积木而盖不成房子。

17.5　全球史与新材料主义：第四个位置

近二十年的两个新趋势值得单独讨论。全球史把研究单位扩大到跨区域互动，试图突破民族国家的框架；新材料主义（物质转向）把物、环境、病原体等“非人类行动者”纳入历史叙事。

这两个趋势共同的特征是试图在高 A 的同时保留较高的 T：既有宏观的多维视野，又有可核对的物质细节。按三角，这必然让出 C。它们目前确实难以给出清晰的因果结论，而是提供“连接”与“关系”的图像。

17.6　转移的动力：约束改变，而非真理逼近

把四个时代并排（图 17.1），可以看到一条清晰的对应：资料状态与坐标位置同步变化。资料稀缺时高 C，资料增加后高 A，资料过载时高 T。约束条件改变了“哪种选择更划算”，范式随之移动。

这个解释有一个重要推论，也是一个可证伪的预测：如果资料环境再次改变（例如人工智能使大规模文本整合变得廉价），轨迹应当再次移动——最可能的方向是回到某种“高 C”，但这次的 C 由数据驱动而非由强假设驱动。［假说，B／乙；预测见第 20.3 节 F1］

需要说清楚这个解释没有主张什么。它不说范式转移与“寻找真相”无关，也不说所有范式在真理面前等价。“约束改变”与“真理逼近”并不互斥。一个更好的提问方式是把两者分到不同的问题上：

  • “为什么换了”这个问题：约束解释给出的是可核对的机制（资料状态、工具环境变了，旧位置不再划算）；“真理逼近”给不出一个可区分的时间点。
  • “换了之后是好还是坏”这个问题：这是价值判断，约束解释不管；一个人完全可以同时认为“约束驱动了转移”与“转移总体上是向真相靠近”。

换句话说，本章反驳的不是“历史学在进步”，而是“进步本身就能解释为什么在这个时间点发生转移”。这两件事不同：前者是关于方向的价值判断，后者是关于机制的经验主张。把“资料从稀缺到过载”看作一项进步，同时又说“是这项变化推动了位置迁移”，两者可以同时为真。［论证，B／乙］

还有一个必须加上的限定，否则本章就会变成单因素论。约束不直接决定哪个范式被采纳，它只限定“哪些选择变得划算”。在同一个成本-收益空间里，具体哪个位置取胜，还要看学术共同体的权力分配（谁掌握刊物、经费、语场）。因此本章的正确表述不是“约束决定范式转移”，而是：约束限定了选择的成本-收益空间，而空间内的胜负由权力分配决定。前者是可检验的机制，后者是社会学问题（第 18 章、附录 I.6）。［论证，乙；O30］

17.6.2　反事实与反例：本章最弱的一环

必须承认：上面的论证到目前为止是相关而非因果。把每个时代的范式特征追溯到那个时代的约束，是事后回溯；它没有证明约束改变导致了范式转移。要把它从相关推到因果，需要反事实与反例。以下两类反例最能伤害本章。

表 17.1　两类反例及其含义
反例若它普遍成立，本章会怎样

资料过载时代坚持高 C 的学者若他们在该时代反而成为主流，则约束与位置的关系被逆转

警告 17.1　循环论证的风险 一个直接的辩护会说：“坚持高 C 的人在资料过载时代会被边缘化，所以主流位置变。”但“边缘化”是靠学术共同体认定的，而共同体正是定义范式的人——这就有循环的风险。要打破循环，需要找一个可独立测量的量：当约束改变时，先前被边缘化的位置是否后来变为主流。如果是，那是支持；如果始终不是，那约束解释就悬了。［警告，乙］
一个自我适用的检验 本书本身也是这个时代的产物：它在资料过载与跨学科工具的环境中，选择了一个元层面的高 C+A 位置。如果约束解释成立，那么本书的风格也应当与它时代的约束相符——它确实如此。［论证，B／乙］

17.7　本章小结

本章的关键产出（保底／有条件／推测）
  • 保底：四个时代的坐标位置与资料状态同步变化，可被逐时代核对。［论证，B／乙］
  • 有条件：范式转移主要由约束改变驱动（而非真理逼近）。［假说，B／乙；O18］
  • 推测：下一个范式会回到数据驱动的高 C。［待验证，F1］
