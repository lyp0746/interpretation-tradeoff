读者指南　一个框架，三种进入方式

你不必按顺序读。全书的进入方式只有三种，对应三类读者。选一种，读完它，再决定要不要读别的。

进入方式一　如果你是历史学家：先看方法，再看它怎么被用

  • 读：第 2 章（内核：诠释即置信度的分配）→ 第 3 章（置信度的四层）→ 第 6 章（人物与事件的还原，含五步清单）→ 第 8—15 章（七场争论的诊断）。
  • 你可以直接用：方法 6.3 五步清单、方法 8.1 诊断四动作、附录 G 工作表。
  • 一句话：这套方法不要求你改变断代判断，只要求你把置信度分配写在别人能反驳的位置。

进入方式二　如果你是理论家：先看内核，再看它的野心

  • 读：第 1 章（问题：为什么争论不收敛）→ 第 2 章（内核）→ 第 16 章（统摄现有理论，含韦伯/汤因比/布罗代尔定位）→ 第 17 章（范式流变）。
  • 核心可辩论点：C、A、T 在史学中是否独立、是否对等（附录 A.3 与 A.5，O4）；置信度分配能否跨传统（O9，P7）。
  • 一句话：本书把“历史学的进步”从“逼近真理”改写为“约束改变后重新分配置信度”。

进入方式三　如果你是怀疑论者：先看它承认自己不行的地方

  • 读：第 5 章（框架的四个“不能”、跨文明警戒线）→ 第 20.5 节（三种可能推翻全书的情形）→ 附录 E（可证伪登记簿）→ 附录 J（一次已撤回的强主张）。
  • 你可以攻击：O1—O5 是生死线；O2（找出“高 C 且高 T”的立场）一个反例即可推翻核心主张。
  • 一句话：本书的强度不在“无懈可击”，而在“靶子明确”。

一条公共的阅读建议

本书把最大的注意力放在“置信度如何被分配”上，而不是历史细节。若某一章的史料对你陌生，跳到每节末尾的诊断框即可；诊断框是自足的。反过来，若你是该领域专家，细节可能显得粗糙——这是刻意的压缩，代价写在每章“本章小结”里。

符号与分级一览（详见第 5.2 节与附录 D）
  • C / A / T：完备性 / 可组合性 / 传递性。在史学中分别对应因果清晰度 / 维度丰富度 / 细节传递性。
  • τ：时间错配比＝对象时间尺度 ÷ 诠释可用的时间尺度。
  • L1–L4：置信度的四层：观察 / 推理 / 诠释 / 因果。
  • 三档置信度：高 / 中 / 低（第 6.3 节，序数，不是概率）。
  • A／B／C：证据等级：官方可复现 / 稳定公开估计 / 稀疏·构造·思辨。
  • 甲／乙／丙：概念等级：成熟形式化 / 清晰机制 / 方向性思辨。
  • O1、O2…：开放问题编号，见第 20.4 节与附录 E。
  • 被让出的顶点：一个框架为了保住两个性质而放弃的第三个。
