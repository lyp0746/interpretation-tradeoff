第 2 章　最小内核：诠释即置信度的分配

法官在“证据不足”和“宁可信其有”之间停了很久。他最后写的不是“是”或“否”，是一句“较可能”。诠释不是表态，是给出一个可以追问的“多可能”。

本章给出本书自己的核心。它不依赖此前任何一本书的结论：历史诠释的最小内核，是给一组命题分配置信度。作者此前四本书中的四个概念——容量、权衡、时间、区分——在这里只被借用为联系的词汇，用来描述这个分配发生的条件。

本章主张 一个历史诠释，无论长短，都在做同一件事：对“发生了什么”“为什么发生”“导致了什么”这一组命题，分配不同的置信度。分配不是任意的，它受四个条件的约束——有限的容量、不可兼得的完备/可组合/传递、诠释时间与历史时间的错配、以及区分所划出的边界。本书的核心是“置信度分配”，四个条件是借来建立联系的语言，而不是这个核心的前提。［论证，B／乙］

2.1　导论：本书自己的核心

前四本书各自有一个中心：记忆与遗忘、知识系统的三角权衡、社会时间的错配、区分与边界。它们处理的是认知、知识、时间、构造。本书处理的是第五个对象——历史诠释——并且它有自己的核心。

这个核心可以在一句话里说完：当一个人诠释历史时，他实际在做的事情，是给一组互相竞争的命题分配置信度。“某人确实说过这句话”置信度很高；“他因此被排挤”置信度中等；“这标志着一个时代的转向”置信度很低。一个诠释的“形状”——它看起来清晰还是复杂、干脆还是含糊——由这组置信度的分布决定。

把诠释看成置信度分配，有三个立刻的好处。第一，它让“诊断”有了可操作的量：不必争论“他这个理论对不对”，只需问“他把多高的置信度放在了哪些命题上，这些置信度与证据是否匹配”。第二，它把第 6 章要展开的贝叶斯与置信度，从一个小技巧变成全书的内核——历史上任何还原，本质都是一次带先验的置信度更新。第三，它使不同学派可以被放在同一把尺度上比较：清晰论、平衡论、细节论的差别，可以被读成三种不同的置信度分配政策。

定义 2.0　三个词的分工 诠释：为命题分配置信度的整个过程（包含亲历者与研究者）。
分析：把一个诠释拆成层次与组成部分的动作（不问对错）。
诊断：对他人诠释的分析，并据此作出可反驳的判断（包含“代价是否被承认”这一类评价）。
三者的关系：诊断 = 分析（诠释）。全书用“诠释诊断”统称这一工作。［定义，甲］
本书的宣言（可被反驳的那一种） 把内核推到极限，本书愿意下一个明确的判断：历史研究中的“进步”，在机制层面首先是“约束改变后重新分配置信度”——而不是“向一个唯一的真相靠近”。同一个对象，在资料状态与工具环境改变之后，划算的分配位置也改变；学科随之迁移。它是否同时更接近真相，是一个价值判断，不是这个机制主张的一部分。（第 17.6 节把这一区分展开。）［论证，B／乙；可由 F1 与 O18 检验］

2.2　约束之一　容量：诠释者先要压缩

置信度不可能被均匀地分配给一切。诠释者的注意力有限，工作记忆有限，他能处理的命题数量有限。容量约束的第一条推论就是：他必须先压缩。面对海量材料，他必须决定“什么值得保留”；这个决定一旦做出，后面的置信度就都建立在一个已经被压缩过的基底上。

压缩不是一次性发生在同一层次，而是沿一条链逐层发生：

  • 观察层：从无数可能的记载里，选出“相关”的那几条。选择标准本身已经是一次压缩。
  • 推理层：从选出的记载里，推出它们意味着什么。每一次推理都会丢掉被判定为“不重要”的枝节。
  • 诠释层：把推理放进一个意图或时代逻辑里，赋予它意义。
  • 因果层：把诠释组织成一条“因为……所以……”的链条。

越往后，可核对的东西越少，而可替代的解释越多。到因果层，一个学者事实上是在众多可能的历史中，选择了一条他愿意让它“发生”的路径——并且给这条路径一个比它的证据所支持的更高的置信度。

定义 2.1　置信度的四层 L1 观察层（文献说了什么）、L2 推理层（它意味着什么）、L3 诠释层（意图与时代逻辑）、L4 因果层（它导致了什么）。层数越高，诠释者可用的核对手段越少，而允许他分配的置信度应当越低。［定义，甲／乙］

这个定义的用处不是给学者排座次，而是给诊断提供坐标。当一个学者写“某制度的僵化导致了某政权的衰落”时，问他这句话在哪一层，能立刻暴露出它的证据位置：L4 的断言，其可核对性远低于 L1，而它常常被赋予像 L1 一样的置信度。

与前作的联系（借用） “容量约束”与作者《遗忘的边界》中的容量级联相连：那本书谈有限容量下的记忆与压缩。本书只借用“压缩有损”这一条，用来描述置信度的分配为什么不可能均匀。它们之间的联系是概念上的，不是论证上的——本书的结论不依赖那本书的结论。［论证，B／乙］

2.3　约束之二　权衡：C-A-T 三角

第二个约束来自一个更抽象的地方：有限的描述无法同时满格三个理想性质。完备性（C）要求每个部分有自洽的内部描述；可组合性（A）要求部分的组合不产生新的非线性项；传递性（T）要求不同尺度或不同主体之间可无损互推。三者至多同时满足两个——这是本书作为一条关于历史诠释的假设提出的，它会在第 4 章与第 8—15 章接受检验。

把这条假设翻译到史学，需要给三个性质各选一个“史学版本”：

表 2.1　C-A-T 的史学翻译与典型表现
顶点史学版本典型表现典型代价
C 完备性因果的完备与清晰“X 之所以发生，是因为 Y”说得干净、可闭合丢失细节与非因果的维度
A 可组合性维度的可组合与模块化经济、政治、思想、环境各维度并行使用无法指出决定性因素
T 传递性结论的传递与时间传递细节可无损地传给读者与下一代研究者难以概括、难以形成规律
翻译的合法性见附录 A.3。三个顶点在史学中并不对等，也不一定独立——这是本书最可能被攻击的地方（O4）。

翻译之后，一个简洁的图像出现了。第 1 章的三种立场，恰好对应三个顶点上的三种“置信度分配政策”：

  • 清晰论把高置信度集中在一个主因上，让出 T：因果链闭合，但细节无法无损传递。
  • 平衡论把置信度分散到多个维度，让出 C：维度丰富，但没有决定性的解释。
  • 细节论把高置信度压在可核对的细节上，让出 C：过程真实，但难以形成总体因果。

三种政策都能在三角里找到自己的位置，也都必须付出一笔代价。这就是为什么争论无法通过“找到更多证据”来终结：证据的增加，不会改变三角的算术。它可以让一个顶点上的工作更精致，但不会让三个顶点同时满格。

警告 2.1　三角不是标签 把学者归到某个顶点，本身就是一次压缩。真实的著作常常在不同章、不同问题上换位置。三角的用处是在同一个问题、同一个尺度上比较选择，而不是给人贴永久的标签。［警告，乙］
与前作的联系（借用） C-A-T 与作者《选择的代价》中的三角相连。那本书把它当作知识系统的约束；本书把它当作一条关于历史诠释的假设重新提出，并在史学中检验。如果它不成立，本书受损，但那本书不受影响——这是“联系”，不是“依赖”。［论证，B／乙］
方法 2.2　从置信度分布到坐标位置——以及这个映射的限度 本书同时使用两种描述：置信度分布（L1–L4 上各承担多少）与 C-A-T 位置（在一个顶点上取舍）。它们的关系是粗粒化，不是同一物。示意性映射：
（a）高置信度集于 L4、L1–L3 较薄 → 倾向高 C、低 T（清晰论）。
（b）高置信度分散在 L2–L3 的多个维度 → 倾向高 A、低 C（平衡论）。
（c）高置信度压在 L1 的可核对细节 → 倾向高 T、低 C（细节论）。
关键警告：这个映射不是一一对应的。多个不同的 L1–L4 分布可以落到同一个 C-A-T 位置；因此坐标是剖面的粗粒化，不能从坐标反推剖面。知道“它是清晰论”，不等于知道它的四层分布。［方法，乙］
图 2.3　从置信度分布到坐标位置——三种典型剖面映射到三个坐标；但多个剖面可落到同一坐标（多对一），因此不可反推。

2.4　约束之三　时间：诠释时间与历史时间

第三个约束是时间。诠释发生在书桌前的一两年里，而它要谈的事件以年、十年、百年计。二者之比，决定了诠释者能分配的置信度有多“细”。

定义 2.2　诠释的时间错配 设 Tobj 为研究对象的时间尺度（如一个王朝的存续时间），Tint 为诠释者可用的时间（通常为一项研究或一代学者的时间），则错配比 τ = Tobj / Tint。τ 越大，诠释越依赖压缩，其结论的“分辨率”越低。［定义，乙］

这个定义解释了史学中一个反直觉的现象。越古老的题目，结论常常越确定。关于罗马帝国为何衰亡的论述，比关于近三十年社会变迁的论述要“干净”得多。按材料的逻辑，这说不通——近现代材料远为丰富。

按容量与时间的逻辑，它就说得通了。古代史的 τ 极大（对象跨越数百年，诠释只占几年），材料稀少，因此诠释者不得不用强假设来填补空白；强假设支持高置信度，于是结论看起来确定。近现代史的 τ 较小，材料过载，细节无法全部纳入，置信度反而被摊薄，结论更谨慎。

一个可检验的推论 如果上述解释成立，那么在同一方法、同一史学传统下，“结论确定性”应当随 τ 增大而上升。这是一个可检验的推论（O3），但它有一个危险的混淆：古代史的确定性也可能来自史料质量的差异。要检验它，必须分离“材料稀少”与“诠释压缩”两个因素。本书尚未完成这个分离。［假说，B／乙］
与前作的联系（借用） “时间错配”与作者《错位的时间》中的 τ 相连。那本书用它描述社会系统的多尺度协同；本书把它换成“诠释者与对象的尺度差”。［论证，B／乙］

2.5　约束之四　区分：诠释即区分，边界即标记

第四个约束是最基础的：诠释就是一连串区分。把什么与什么分开，把什么与什么归并，在哪一个尺度上说话，到哪里为止——每一次区分都会改变置信度的分布。

一个历史诠释至少包含五层区分：

表 2.2　诠释的五层区分
区分层在问什么一个例子
观察区分哪些材料算“相关”只看政治史文献，还是也纳入墓志、账簿、气候记录
因果区分哪个因素是“主”，哪些是“辅”把财政崩溃当作主因，还是把军事压力当作主因
压缩区分把多少材料压成几条线索三千条记载 → 三十个事件 → 三条主线
语境区分哪些是“当时的”，哪些是“我的”“衰落”是当时的观念，还是后人的类比
边界区分到哪里为止，什么条件下失效这个结论只在“中央权力可观测”的尺度上成立
区分层的划分是对《区分的语法》中“区分”概念的定性转写，不继承其代数命题；转写见附录 A.3。

关键在最后一层。一个诠释是否负责任，很大程度上取决于它有没有标记自己的边界。前四层区分难以避免，但第五层可以被省略——而省略它，就意味着把一次有条件的置信度分配，伪装成一个无条件的结论。

本节的诊断动作 “区分”给了诊断一个可操作的抓手：面对一个诠释，先问它做了哪些区分，再问它标记了哪些边界。没有标记边界的地方，往往就是它最脆弱的地方——也是学术争论最集中的地方。［论证，B／乙］

2.6　诊断五步：四者如何协同

四个约束不是四个独立视角，而是一条链（图 2.1）。但在把它们连成一条链之前，必须先说清楚一件事：它们不是同一类东西。

定义 2.3　约束的三种类型 认知性约束（容量、时间）：来自研究者一侧——注意力有限、研究时长有限。可以靠工具缓解（检索、计算、合作），但不会消失。
逻辑性约束（权衡）：来自概念结构——完备/可组合/传递在有限描述中定义上互斥。不能靠更多资源缓解；它是形式性的。
符号性约束（区分）：来自符号系统——意义需要边界才能成立。可以通过新的形式化缓解（新的记号、新的区分方式），但会引入新的边界。
三者为什么能并置：它们都作用于同一个操作——置信度的分配。认知性约束限制“能分配多少”，逻辑性约束限制“能同时保住几个顶点”，符号性约束限制“分配的颗粒度”。［定义，甲／乙］
图 2.2　约束的三种类型——来源不同，后果不同：认知性可缓解、逻辑性不可缓解、符号性可通过新形式化移动。

这个分类有一个直接后果：“约束”不是一个统一的东西，因此“消除约束”也不是一个统一的目标。工具能拓宽认知性约束；新的形式化能移动符号性约束；但逻辑性约束不能被“解决”，只能被选择。第 21.5 节关于“约束从何而来”的追问，正是从这里开始的。［论证，乙］

方法 2.1　诠释诊断五步 第一步（容量）：把这个诠释分解到 L1–L4，看它的高置信度堆在哪一层。
第二步（权衡）：判断它在 C-A-T 中保住了哪两个顶点、让出了哪一个。

2.7　一次具体的置信度分配：三个假设、两件证据

“诠释就是给竞争命题分配置信度”这句话，如果不算一次，就还是口号。这一节算一次，数字很小，但每一步都可以复核。

设定。 三个竞争假设：H₁（某政策是“个人冒险”）、H₂（是“制度惯性”）、H₃（是“时代结构”）。先验：0.5 / 0.3 / 0.2。两件证据：E₁（一份支持“个人决策”的私人书信）、E₂（一组显示“制度约束”的统计序列）。似然（在各自假设下看到这件证据的概率）由研究者给出：E₁ = 0.8 / 0.5 / 0.2；E₂ = 0.3 / 0.6 / 0.9。

计算。 贝叶斯更新就是“先验 × 似然，再归一化”。

阶段H₁H₂H₃
先验0.5000.3000.200
看到 E₁ 后0.6780.2540.068
再看到 E₂ 后0.4880.3660.146

读法一：证据可以改变排序，但不一定改变结论。 E₁ 让 H₁ 领先（0.678），E₂ 把差距拉近（0.488 对 0.366），但 H₁ 仍然领先。这就是“证据有分量，但没有翻盘”的样子。

读法二：先验的强度决定结论的稳定性。 把先验换成 0.7 / 0.2 / 0.1，同样两件证据之后是 0.683 / 0.244 / 0.073——H₁ 赢得更稳。把先验换成均匀的 1/3、1/3、1/3，结论就翻了： 0.340 / 0.412 / 0.248，H₂ 领先。

读法三：翻盘的关键，往往不是证据，而是“你一开始有多确定”。 这在史学里有一个很实际的对应：两个史家看到同一批材料却得出相反结论，很可能不是谁读错了，而是他们的先验不同。 而先验通常不被写出来——这就是本书主张“把先验也标注出来”的理由。

人的尺度

一位口述史受访者讲了一下午，最后说：“你别写我说得对，你写我当时就是这么想的。”她要的不是被赞同，是被准确地记住——包括她的错。把诠释看作置信度分配，第一件好处就是：你可以不同意一个人，同时仍然准确地记下他。

2.8　小结：与前四本书的联系，而非依赖

必须把“联系”和“依赖”分开说清楚，因为这是本书最容易读错的地方。本书的结论不建立在此前四本书的结论之上；它只借用了四个概念作为联系的词汇。下表说明这种联系的性质。
