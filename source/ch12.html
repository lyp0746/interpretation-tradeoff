第 12 章　三十场争论的权衡坐标

六场深度诊断之后，本章把框架铺开：三十场历史学、政治学、社会学与经济学中的持久争论，各自给出一个坐标。目的不是给出三十个答案，而是检验框架能否在同一张表上比较它们——并诚实追问，这张表究竟在测量学术现实，还是在投射框架自己。

本章主张 三十场争论在坐标上呈现出稳定的模式：高 C 的立场系统性地让出 T，高 T 的立场系统性地让出 C，而最具争议的问题集中在 A 与 T 之间。但本节同时提出一个自我否定式的检验：这三个“规律”有可能只是分类框架的投射。［论证，B／乙 / 反例见 12.5］

12.1　导论：从六个到三十个

深度诊断的价值在于细致，代价在于无法回答“框架是否普适”。本章用数量换普适性：用统一的坐标规则处理三十场争论，看它会不会崩溃。如果三十场里有一大半无法被定位，或者定位之间毫无模式，那么框架的普适性就值得怀疑。

为了避免重复，本章的三十场争论刻意避开第二部分的六个深度案例，选取历史学、政治学、社会学、经济学、法学、艺术史中的其他持久问题。

12.2　快速诊断的方法与限度

快速诊断使用与深度诊断相同的五步（方法 2.1），但被压缩为三个动作：

  1. 定位三派：把每场争论的立场大致归为清晰论、平衡论、细节论三组。
  2. 给出坐标：按附录 A 的规则，给出 C/A/T 的高、中、低与让出的顶点。
  3. 写一句诊断：指出这场争论的分歧首先出在哪个环节（定义、层次、还是因果归属）。
警告 12.1　快速诊断的三个限度 （1）坐标是 B 级判断，不同研究者会给出不同读数。
（2）把立场归为三组本身是一次压缩，真实争论可能更复杂。
（3）一句话诊断不能替代深度研究，它只是提问的起点。［警告，乙］

12.4　四条从坐标中浮现的规律

把三十行按 C 与 T 排序，会浮现出四个模式。它们与第 1—4 章的预测大致吻合。

  1. 高 C 的立场几乎都让出 T。表中标注“让出 T”的立场，C 普遍为高。因果闭合与细节传递构成交换关系。
  2. 高 T 的立场几乎都让出 C。细节充分的研究，很少给出单一因果结论。
  3. 最具争议的问题集中在 A 与 T 之间。纯粹高 C 的问题（如“某份文书真伪”）争议小；纯粹高 T 的问题（如“某个村庄发生了什么”）争议也小。争议最大的是“多维且具体”的问题——这类问题既要求丰富维度，又要求可核对细节，因而最难同时保住两个顶点。
  4. “让出 C”的立场数量多于“让出 T”的立场。表中 A 高或 T 高的立场合计超过半数。这可能反映一个学术现实：现代史学的重心偏向复杂性与细节；也可能只是我的样本偏差（见 12.5）。

12.5　规律是否只是框架的投射

必须在这里停下来。上面四条“规律”看起来很整齐，而整齐本身就是可疑的。

如果一个框架用三个类别去描述所有对象，它当然会找到三个类别的模式——这可能只是分类的自证。要区分“真实模式”与“投射”，唯一的方法是让框架接受可能推倒自己的检验。下面给出三种检验，并把它们登记为开放问题。
