# 数据与文献来源

本书是一份**理论/诊断**著作，其“数据”主要是对公开史学文献的形式分析，而非统计序列。因此它的来源分为三类。

## 1. 史学文献（主要来源）

- 各章讨论的著作与学派见正文附录 C（参考文献线索）。
- 文献仅以作者、书名/主题方式引用；版本、页码与译名由读者核对原书。
- 所有对文献的处理都是**元层面**的：诊断其诠释形式，不裁决其史料内容。

## 2. 公开历史年代与通行叙事（A 级）

- 第 6.5 节的帝国存续区间、第 6.5 节的时间尺度对照等采用通行年代。
- 这些年代为可核对的历史事实；围绕它们的“衰落期”划分为诠释选择（B/C 级）。

## 3. 示意性数字（C 级）

- 第 3.7 节的示例、第 6.5 节的 τ 量级、附录 K 的尺度表均为**示意**，仅作方向判断。
- 凡是示意数字，正文或附录均标明；不得转引为经验事实。

## 数据缺口

无法获得或质量不足的数据登记于 `docs/DATA-GAPS.md` 与正文附录 F。

## 可复现部分

- 坐标评分规则（附录 A）可被读者独立复算。
- 校对与构建脚本（`analysis/audit.py`、`build_book.py` 等）均可重跑。
- 可证伪登记簿（`docs/preregistration/`）为机器可读，可核销追加。
