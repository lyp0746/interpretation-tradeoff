# 欢迎补充数据

本书是一份开放的研究纲领。它明确标出了自己无法完成的检验，并欢迎读者接手。最有价值的补充有三类：

## 1. 独立评分（O5）

按附录 A 的评分规则，对第 12 章的三十场争论或自选争论做一次独立评分，记录你在每一档上与书中读数的差异。最小交付：一张坐标表 + 一句分歧说明。

## 2. 反例搜索（O2）

寻找一个**同时高 C、高 A、高 T** 的主流史学立场。给出一个成立的反例，即可推翻本书的核心主张二。最小交付：一个立场 + 它的坐标证据。

## 3. 分层证据密度（O1）

测量同一史料集在不同研究中各层（L1–L4）的证据密度，检验“逐层衰减”是否成立。最小交付：一个可比口径的测量表。

## 其他开放问题

O1—O22 完整清单见正文附录 L。每个问题都给出一个可以最小化执行的检验动作。

## 如何提交

通过 GitHub Issue 或 Pull Request 提交。可证伪登记簿为 append-only：补充数据以**追加**方式记录，不改写旧行。

> 验证不是对作者的信任，而是对读者自己的尊重。
