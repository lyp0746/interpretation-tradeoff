# 方法论

本书的方法论由四把工具、一条诊断流程、以及一套分级纪律组成。

## 四把工具

| 工具 | 来源 | 在本书中的作用 |
|---|---|---|
| 容量级联 | 《遗忘的边界》 | 诠释四层（观察/推理/诠释/因果），逐层可核对性下降 |
| C-A-T 三角 | 《选择的代价》 | 完备/可组合/传递三选二；史学风格的顶点位置 |
| 时间错配 τ | 《错位的时间》 | 对象尺度 ÷ 诠释尺度，限定结论分辨率 |
| 区分与边界 | 《区分的语法》 | 诠释即区分；边界必须被标记 |

## 诊断流程（方法 2.1）

1. **容量**：把诠释分解到 L1–L4，找最弱的一层。
2. **权衡**：判断它保住哪两个顶点、让出哪一个。
3. **时间**：估计 τ，指出这个 τ 允许说多细。
4. **区分**：列出五层区分，找出未标记边界的接口。
5. **复核**：写出一个能推翻这个诊断的最小行动。

## 分级纪律

- **证据等级**：A（官方可复现）/ B（稳定公开估计）/ C（稀疏·构造·思辨）。
- **概念等级**：甲（成熟形式化）/ 乙（清晰机制）/ 丙（方向性思辨）。
- **结论强度 ≤ 证据强度**。C 级只作方向判断。
- **三层结论**（定义 16.1）：地板（保底，不依赖经验结论）/ 天花板（有条件）/ 阁楼（推测）。

## 评分规则

C/A/T 只使用高、中、低三档，每档给出判定锚点（附录 A）；“让出的顶点”取三档中最低者（规则 A.1）。评分为 B 级判断，允许读者复评并获得不同数值。

## 可证伪性

- 核心主张 P1—P5 与预测 F1—F5 登记于附录 E 与 `docs/preregistration/`。
- 登记簿为 append-only。
- 框架自身的一次失效（撤回“坐标可形式化”的强主张）记录于附录 J。

## 适用边界

- 框架最适用于**同一学术传统内部**、已文献化的争论。
- 跨文明使用时有三条警戒线（警告 5.1）：对象无“因果清晰度”概念、诠释不以文本存在、不区分事实与意义。
- 本书自评为“C+A、让出 T”，可由 O8 自指一致性检查推翻。
