# 方法论

本书的方法论由一个自有的内核、四个借来的约束、一条诊断流程，以及一套分级纪律组成。

## 自有内核（不依赖前作）

**历史诠释，就是给一组互相竞争的命题分配置信度。**“他确实说过”置信度高；“他因此被排挤”置信度中；“这标志一个时代的转向”置信度低。一个诠释的形状，由这组置信度的分布决定。

## 四个借来的约束（联系，而非依赖）

| 约束 | 相连的著作 | 在本书中的作用 |
|---|---|---|
| 容量 | 《遗忘的边界》 | 置信度不可能均匀分配，必须先压缩 |
| 权衡 | 《选择的代价》 | 完备/可组合/传递三选二；史学风格的顶点位置 |
| 时间 τ | 《错位的时间》 | 对象尺度 ÷ 诠释尺度，限定结论分辨率 |
| 区分 | 《区分的语法》 | 诠释即区分；边界必须被标记 |

借用关系见附录 H：若某个借用不成立，本书的核心不受影响。

## 诊断流程（方法 2.1）

1. **容量**：把诠释分解到 L1–L4，看它的高置信度堆在哪一层。
2. **权衡**：判断它保住哪两个顶点、让出哪一个。
3. **时间**：估计 τ，指出这个 τ 允许说多细。
4. **区分**：列出五层区分，找出未标记边界的接口。
5. **复核**：写出一个能推翻这个诊断的最小行动。

## 五个应用（由深而广）

1. 贝叶斯与置信度 → 人物与事件的还原（第 6 章）。
2. 数据分析 → 跨文明制度对比（第 7 章）。
3. 分析还原论 → 既有争论（第 8—14 章）。
4. 综合分析 → 统摄现有理论（第 15 章，定位而非合并）。
5. 范式转移 → 理论流变（第 16 章）。

## 分级纪律

- **证据等级**：A（官方可复现）/ B（稳定公开估计）/ C（稀疏·构造·思辨）。
- **概念等级**：甲（成熟形式化）/ 乙（清晰机制）/ 丙（方向性思辨）。
- **结论强度 ≤ 证据强度**。C 级只作方向判断。
- **三层结论**（定义 19.1）：地板（保底，不依赖经验结论）/ 天花板（有条件）/ 阁楼（推测）。

## 评分规则

C/A/T 只使用高、中、低三档，每档给出判定锚点（附录 A）；“让出的顶点”取三档中最低者（规则 A.1）。置信度用三档（高/中/低，第 6.3 节）。所有评分均为 B 级判断，允许读者复评并获得不同数值。

## 适用边界

- 框架最适用于**同一学术传统内部**、已文献化的争论。
- 跨文明使用时有三条警戒线（警告 5.1）：对象无“因果清晰度”概念、诠释不以文本存在、不区分事实与意义。
- 本书自评为“C+A、让出 T”，可由 O8 自指一致性检查推翻。
