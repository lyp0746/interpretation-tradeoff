# 读者说明

《诠释的权衡：为什么历史学永远有争论——诠释的容量、权衡、时间与边界》
李毅芃　著　·　2026　·　CC BY 4.0

## 这是什么

一本史学理论专著与诊断手册。它不判定任何史学争论中哪一派正确，而是给出一个坐标，标出每一派在容量上压缩了什么、在三角上让出了哪个顶点、面对多大的时间错配、在哪些条件下失效。

## 怎么读

- **十分看懂**：先读“先读这一页”与“十分钟读懂本书”。
- **只想看框架**：第 1 章 → 第 4 章 → 第 16 章。
- **关心具体争论**：第 2 章 → 第 6—11 章（六场深度诊断）。
- **想快速查坐标**：第 12 章 + 附录 B。
- **怀疑论者**：第 5 章 + 附录 E（可证伪登记簿）+ 附录 J（框架自身失效）。

## 符号约定

- **C / A / T**：完备性 / 可组合性 / 传递性；在史学中分别对应因果清晰度 / 维度丰富度 / 细节传递度。
- **τ**：时间错配比＝对象时间尺度 ÷ 诠释可用时间尺度。
- **L1–L4**：容量级联四层：观察 / 推理 / 诠释 / 因果。
- **A/B/C**：证据等级；**甲/乙/丙**：概念等级。
- **［已知］［论证］［假说］［待验证］**：断言标记。
- **O1—O22**：开放问题；**F1—F5**：可检验预测。

## 一句话

**历史学里的争论，大多不是谁对谁错，而是谁在哪张价目表上付了哪一笔；本书给出一套坐标，把每一笔账标在明处。**
