# 读者说明

《诠释的权衡：历史研究中的置信度、权衡与理论流变——从人物还原到范式转移的五个应用》
李毅芃　著　·　2026　·　CC BY 4.0

## 这是什么

一本史学理论专著与诊断手册。它的核心：**历史诠释就是给一组互相竞争的命题分配置信度。** 它不判定任何史学争论中哪一派正确，而是标出每一派把置信度分配在了哪里、面对什么约束、在哪些条件下失效。

## 怎么读

按“由深而广”的五个应用：

1. **应用一（第 6 章）** 贝叶斯与置信度 → 历史人物与事件的还原。
2. **应用二（第 7 章）** 数据分析 → 跨文明制度对比。
3. **应用三（第 8—14 章）** 分析还原论 → 既有的历史研究争论。
4. **应用四（第 15 章）** 综合分析 → 统摄现有的历史理论。
5. **应用五（第 16 章）** 范式转移 → 历史研究理论的流变。

其他入口：
- **十分看懂**：先读“先读这一页”与“十分钟读懂本书”。
- **只想看内核**：第 1 章 → 第 2 章 → 第 3 章 → 第 19 章。
- **怀疑论者**：第 5 章 + 附录 E（可证伪登记簿）+ 附录 J（框架自身失效）。

## 符号约定

- **C / A / T**：完备性 / 可组合性 / 传递性；在史学中分别对应因果清晰度 / 维度丰富度 / 细节传递度。
- **τ**：时间错配比＝对象时间尺度 ÷ 诠释可用时间尺度。
- **L1–L4**：置信度的四层：观察 / 推理 / 诠释 / 因果。
- **三档置信度**：高 / 中 / 低（序数，不是概率）。
- **A/B/C**：证据等级；**甲/乙/丙**：概念等级。
- **［已知］［论证］［假说］［待验证］**：断言标记。
- **O1—O28**：开放问题；**F1—F5**：可检验预测。

## 与系列的关系

本书有自己独立的核心，不依赖前四本书的结论；四个概念（容量、权衡、时间、区分）只是**借用**来建立联系的词汇。详见附录 H。

## 一句话

**历史学里的争论，大多不是谁对谁错，而是谁把多高的置信度放在了哪些命题上；本书给出一套坐标，把每一笔账标在明处。**
