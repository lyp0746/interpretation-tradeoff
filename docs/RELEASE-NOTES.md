# 修订说明（内容构成与阅读路径）

本书的正文以 `source/*.html` 为唯一权威来源，经统一管线生成印刷版 PDF、电子阅读版 PDF、EPUB 3、网页版与 Markdown 版。发布包包含：

- `interpretation-tradeoff-print.pdf`：印刷/正式版 PDF（A4，宋体 + Times，四级书签）
- `interpretation-tradeoff-ereader.pdf`：电子阅读版 PDF（B5 重排）
- `interpretation-tradeoff.epub`：EPUB 3（nav + NCX 四级目录）
- `interpretation-tradeoff.html`：网页版（自包含）
- `interpretation-tradeoff.md` / `interpretation-tradeoff-markdown/`：合并与分文件 Markdown
- `cover.svg`：封面矢量图
- `README.md`、`修订说明.md`、`数据缺口清单.md`、`欢迎补充数据.md`

## 内容构成

1. **最小内核**（第 1—5 章）：问题、核心（诠释即置信度的分配）、四个借来的约束、诊断边界。
2. **五个应用，由深而广**（第 6—17 章）：
   - 应用一：贝叶斯与置信度 → 人物与事件的还原（含五步清单与三个案例）；
   - 应用二：数据分析 → 跨文明制度对比（含十个政权—时期的编码示范）；
   - 应用三：分析还原论 → 既有争论（七场案例，含唐宋变革；含十场深化与二十场范围预估）；
   - 应用四：综合分析 → 统摄现有历史理论（含韦伯/汤因比/布罗代尔定位）；
   - 应用五：范式转移 → 历史研究理论的流变。
3. **元反思**（第 18—19 章）：跨学科的权衡冲突、诠释的责任。
4. **边界与纲领**（第 20—21 章）：用同一套标准给本书打分、可检验预测、开放问题。

## 严谨性约定

- 全书结论按 A/B/C 证据等级与甲/乙/丙概念等级双重标注，结论强度不超过证据强度。
- 可证伪登记簿为 append-only；框架自身的一次失效记录于附录 J。
- 评分与置信度规则见附录 A，读者可据同一规则重评并获得不同数值。
