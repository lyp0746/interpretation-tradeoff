## 本轮更新（2026-10-18）

- **每章新增“叙事导言”。** 25 章各加一段场景开场（约 1–2 句），随后进入论证；不改变章节编号、不改变任何结论与分级。
本轮不改变任何核心主张，只做三件事：<b>把“人”放回论证里</b>。

- **每章新增“人的尺度”。** 25 章各加一段具体处境（医生、病人、学生、教师、研究者、普通劳动者），写明这条机制/约束<b>由谁承担代价</b>；不做抒情，只做归账。
- **前言新增“我为什么写这本书”。** 一段第一人称的写作动机，放在导语之后；不替代学理交代，只说明作者为什么非写不可。
- **时间锚与用语纪律。** 版权页加注：正文中的“当代／目前／当前／最近”，除另有注明，一律指截至 2026 年 10 月的情形；全库复查“必然／注定／无法避免／死路”一类宿命化表述，结论性用法清零（技术性表述改用“逻辑强制”“在这组假设下”等）。

正文、图表、登记簿、分级均未改动；页数因增补而略有增加。

## 内容构成

1. **最小内核**（第 1—5 章）：问题、核心（诠释即置信度的分配）、四个借来的约束、诊断边界。
2. **五个应用，由深而广**（第 6—17 章）：
   - 应用一：贝叶斯与置信度 → 人物与事件的还原（含五步清单与三个案例）；
   - 应用二：数据分析 → 跨文明制度对比（含十个政权—时期的编码示范）；
   - 应用三：分析还原论 → 既有争论（七场案例，含唐宋变革；含十场深化与二十场范围预估）；
   - 应用四：综合分析 → 统摄现有历史理论（含韦伯/汤因比/布罗代尔定位）；
   - 应用五：范式转移 → 历史研究理论的流变。
3. **元反思**（第 18—19 章）：跨学科的权衡冲突、诠释的责任。
4. **边界与纲领**（第 20—21 章）：用同一套标准给本书打分、可检验预测、开放问题。

## 严谨性约定

- 全书结论按 A/B/C 证据等级与甲/乙/丙概念等级双重标注，结论强度不超过证据强度。
- 可证伪登记簿为 append-only；框架自身的一次失效记录于附录 J。
- 评分与置信度规则见附录 A，读者可据同一规则重评并获得不同数值。
