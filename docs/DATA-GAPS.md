# 数据缺口清单

本书涉及的许多判断依赖公开文献与公开数据的质量。本清单如实登记无法获得、或质量不足的数据，说明缺口的原因与获取路径。完整版见正文附录 F。

## 缺口

| 缺口 | 原因 | 对本书的影响 | 获取路径 |
|---|---|---|---|
| 独立评分者一致性数据 | 需组织双盲评分 | 坐标稳健性（P5）无法确证 | 与高校合作开展评分实验（O5） |
| 四层证据密度的可比测量 | 计量口径未标准化 | 容量主张（P1）仅有定性支持 | 建立史学研究的分层标注数据集 |
| 史料质量与诠释压缩的分离 | 两者在真实材料中高度混淆 | 时间主张（P3）不可直接检验 | 选“材料充足但对象久远”的题目做对照（O3） |
| 跨文明诠释的等价标准 | 不同传统诠释概念无法直接对应 | 第 5.5 节适用边界只能定性 | 与各传统研究者合作做转写研究（O9） |
| 坐标表的完整文献支撑 | 三十场争论各需专业清理 | 附录 B 为示意性坐标 | 由各领域专家分头审校（O5） |

## 处理原则

1. **不伪造**：没有可靠来源的数字一律标注为示意（C 级）。
2. **不隐藏缺口**：无法获得的数据写入本清单，而不从叙述中删去。
3. **不把方向当数值**：C 级结论只作方向判断。
4. **不转引二手**：文献目录为线索性选目，版本与页码由读者核对原书。
